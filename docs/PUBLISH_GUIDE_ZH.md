# 发布准备与操作

候选文件位于项目的 `artifacts/release_candidate_v1`。目标账户与仓库为 `jinzzze/simu-lab`。已创建公开仓库 https://github.com/jinzzze/simu-lab ，源码报告已推送。用户已授权公开全部原片、处理后数据和权重；v1.0.0 Release 用于分发校验过的附件。正式岗位申请仍未提交。

1. 审阅英文 README、申请说明、112 秒演示和发布清单。演示与部分诊断图片含个人采集的手部画面；源码报告包也不是纯文本。
2. 确认源码许可证。建议 MIT，仅对你有权授权的原创源码生效；原片、衍生数据和权重另行决定。当前没有生效的根 LICENSE。
3. 登录 GitHub 后创建公开 `simu-lab` 仓库。为防止原环境或大型权重误入 Git，上传整理后的 `repository` 文件夹内容，而非整个原项目。
4. 该文件夹已经过文件清单审计。它包含 `.gitignore` 原始排除规则；首次 Git 暂存时需在这个**整理后的文件夹**中使用 `git add -f -- .`，才能包含已审阅的演示与非权重运行证据。不要在原项目根目录使用这个命令。填写自己的 Git 提交身份后提交，再向新建仓库推送。
5. 将批准公开的 ZIP 作为 GitHub Release 附件。较大的 inputs/checkpoints ZIP 含原始视频和模型，需先确认公开范围与相应条款。第三方基础模型没有捆绑，采用官方 URL 加哈希下载。
6. 使用未登录窗口验证仓库和 Release 附件，填入申请表。截止时间为 2026-10-09 23:59 BST。表单还需要本人姓名、邮箱、简历、教育经历及英国工作授权状态。

两个 ZIP 解压到同一目录后运行 `scripts/verify_release.py`。`SHA256SUMS.txt` 是 ZIP 校验清单。代码报告包可离线阅读；实际复现还需数据权重附件、环境安装与外部基础模型。禁止把本地路径或尚未创建的仓库地址当作可访问的公开交付链接。
