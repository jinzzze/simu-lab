# 抓取仿真原型与控制诊断

日期：2026-10-06。状态：真实物理抓取后端、固定控制器与评分已实现；这是控制诊断，不是 A/B/C/D 模型实验结果。

## 实现范围

当前任务按用户确认的样片定义：20 × 20 × 10 mm 黑方块从左侧起始区抓起，放到黑线右侧，松手并撤开。旧推杆、推动动作菜单和推动世界模型没有沿用。当前是固定抓取状态机原型，不宣称实现了世界模型或学会了人手到机械臂的动作映射。

- 后端：panda-gym Panda + PyBullet 物理接触，桌面 z=0，世界 +X 对应固定俯视图向右。
- 控制流程：接近、下降、闭合、抬起、向右搬运、下降放置、张开、撤离。
- 控制器接收一次外部物体 XY 预测，以及共同的已知方块高度、目标定义和机器人自身状态。它不读取物体真值来重选抓取点、纠偏或重试。
- 夹取使用 Panda 原生双指接触与摩擦。没有附着约束、吸附、抓后传送或直接改变物体位置；reset 时仅设置初始场景。
- 每个控制步 0.04 秒（20 个 0.002 秒物理子步），末端每步指令移动最多 8 mm。

## 共同场景和声明的假设

配置在 `configs/grasp_sim.json`。物体尺寸来自用户；质量 20 g、物体摩擦 0.8、指端摩擦 1.4、20 N 指关节力、相机、工作区和线坐标都是开发假设，并非已从视频精确标定。

起始中心 x∈[-0.10,-0.035] m，y∈[-0.055,0.055] m，yaw=0。方块落桌后的初始姿态有物理求解器的微小误差。黑线中心 x=0.045 m、宽 3 mm，因此右边缘 x=0.0465 m。共同放置指令为 [0.10,0] m。工作区 x∈[-0.15,0.16] m、y∈[-0.12,0.12] m。

固定俯视相机位于 [0,0,1] m，22° 视场，224 × 224 RGB，桌面视野约 0.389 m；方块约 12 像素宽。初始末端在 [-0.20,0,0.10] m，位于工作区左侧。仿真目前绘制起始框与黑线，没有复刻 ArUco、纸上网格、真实灯光和人手外观；这些是域差异，不能声称精确数字孪生。

## 成功判定

以 25 Hz 控制步采样仿真真实状态，评分与控制决策分离。成功须同时满足：

1. 操作过程中，方块最低角点离桌至少 15 mm，且 Panda 左右两指（link 9/10）同时有正法向接触力（>1e-5 N），连续采样至少 0.12 秒。仅沿桌面推、偶然弹起或悬空假姿态均不足以满足此判据。
2. 物体八个三维角点投影的最左边 x 严格大于 0.0465 m；中心过线不算完全过线。
3. 全部角点的 XY 均位于共同工作区，物体与桌面有接触，最低点距离桌面不超过 2 mm。
4. 物体保持正面向上，倾斜不超过 20°。
5. 指宽至少 40 mm、机器人与物体无接触，末端距离物体中心至少 60 mm。
6. 线速度 <5 mm/s、角速度 <0.1 rad/s，且上述最终放置条件连续满足至少 0.5 秒。

真值位姿、速度和接触只用于标签、评分及明确标注的 oracle 诊断。`execute_grasp` 的最终诊断输出包含真值结果，但控制轨迹已经执行完毕，不利用这些结果进行同次纠偏。

## 接口

```python
from src.sim import GraspEnv

env = GraspEnv(image_size=224)
obs = env.reset(seed=10000)         # {'rgb', 'proprio', 'goal'}
rgb = obs['rgb']                    # H×W×3 uint8 RGB
xy_label = env.get_object_xy_for_labels()  # 仅适配训练标签或明确 oracle
# 正式视觉评测必须由 model(rgb) 给出米制 XY，不能使用上面的标签。
result = env.execute_grasp(predicted_xy_m, record=False)
env.close()
```

`render()` 返回当前俯视 RGB；`get_object_label()` 额外返回米制 XY 和相机归一化 UV（特权标签接口）；`record=True` 时 `env.frames` 保存斜视演示帧，按 12.5 fps 导出。
