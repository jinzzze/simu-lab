# Third-party sources and release review

This is a source and provenance notice, not a blanket license grant for data or model weights. The project source license is pending owner selection; `docs/LICENSE_PROPOSAL.md` contains the proposal. Dependency distributions retain their own notices. No Python environment or third-party package source is included in the source archive.

- **TorchVision / ResNet-18.** Architecture and implementation: https://github.com/pytorch/vision ; software license: https://github.com/pytorch/vision/blob/main/LICENSE . The official README explicitly states that pretrained models may have separate terms derived from their training datasets: https://github.com/pytorch/vision#pre-trained-model-license . Therefore neither the original ImageNet checkpoint nor the fine-tuned visual checkpoints are declared covered by a proposed project-source MIT license. The base checkpoint is excluded from release archives and fetched from the official URL with the recorded hash.
- **MediaPipe Hand Landmarker.** https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker ; source license: https://github.com/google-ai-edge/mediapipe/blob/master/LICENSE . The official linked model card identifies Apache 2.0 and describes limitations under occlusion, including holding objects: https://storage.googleapis.com/mediapipe-assets/Model%20Card%20Hand%20Tracking%20(Lite_Full)%20with%20Fairness%20Oct%202021.pdf . This directly limits interpretation of the grasp-video pseudo labels. The model binary is not bundled; the download and hash are in `configs/model_sources.json`.
- **PyBullet / Bullet and Panda assets.** https://github.com/bulletphysics/bullet3 ; license: https://github.com/bulletphysics/bullet3/blob/master/LICENSE.txt . Installed through conda-forge; simulator assets are provided by the installed dependencies, not relabeled as project assets.
- **panda-gym.** https://github.com/qgallouedec/panda-gym . The repository's license and distribution notices apply to its code/assets.
- **Diffusion Policy method.** Cheng Chi et al., “Diffusion Policy: Visuomotor Policy Learning via Action Diffusion,” RSS 2023. Official project/repository: https://github.com/real-stanford/diffusion_policy . This project provides a compact separate implementation, not an official benchmark replication. No official trained policy weights or demonstration dataset is redistributed.

The source archives contain locally authored project code and reports; data/checkpoint archives are separate local candidates. The applicant approved public distribution of recordings and derived checkpoints on 2026-10-07. That approval does not supersede third-party terms. The full installed version inventory and exact Windows lock files accompany reproduction documentation. Primary URLs were reviewed on 2026-10-07; this list does not certify every downstream use.
