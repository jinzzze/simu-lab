# 第一轮手机试采（12 次）

状态：用户已确认手机可固定俯拍，也能打印标记。先完成本轮试采和质量检查，再决定正式采集参数；本轮不是正式144条训练集。

当前使用双标记版 `pilot-a4-diagonal-2-v1`：左上ID 0、右下ID 2，均为30mm。请使用更新后的打印文件。已经打印的旧版可完全遮住右上ID 1和左下ID 3，并保持纸张平整及其余标记位置不变。若已经拍摄过旧版视频，保留原片并单独记录板版本，不将其伪装成双标记版。

## 1. 准备

- 手机固定俯拍，后置摄像头普通视频，优先1080p/30fps，保持同一镜头和方向。尽可能锁定对焦/曝光，关闭数字变焦和美化。
- 桌面照明均匀，方块与背景颜色有明显差异。记录方块的长、宽、高和推头宽度（毫米）。
- 使用一个缓慢推动物体的刚性推杆，握杆时尽量露出手背/指节。保持手、推杆尖端、物体都在画面内。
- 打印 `assets/calibration/print_board.html` 或 `pilot_board_a4.svg`：A4纵向、100%/实际大小、不要适应页面；关闭页眉页脚。
- 用真实尺子量底部标尺，必须为50mm；有偏差先修正打印设置。将纸平整固定在桌面，左上角ID 0和右下角ID 2两个标记都要入镜，尽量避开手臂遮挡。
- 中心工作区域只适合短推试采。如物体尺寸过大，先记录尺寸和问题，不临时缩放打印板。

## 2. 单次拍摄步骤

1. 拍摄开始前按下表选好动作，记录episode_id和a_cmd，不根据结果反推动作。
2. 把方块放在工作区中央，初始方向尽量与纸面坐标对齐。
3. 录制约2秒静止画面，再从指定接触侧缓慢沿内法向推动；最后保留约2秒静止结果。
4. 接触偏移是相对于该面中心的偏移；本轮先用居中与一个小偏心位置。
5. 推送长度是预先计划的推杆行程。以标尺/网格辅助，不把物体最终位移当作指令长度。
6. 保留原片，包括推不动、旋转、滑移和遮挡失败；在记录中标注，不剪掉失败后重新命名为成功。

## 4. 每条记录

至少记录：episode_id、原始文件名、日期/批次、标定板版本、方块尺寸、推头尺寸、接触侧、偏移、计划推送长度、相机设置、是否偏离指令、遮挡或其他问题。记录计划动作和实际结果是两件不同的事。

## 5. 试采后的检查

- 视频能解码且时间顺序正确；未发生自动换镜头、严重模糊或画面抖动。
- 开始/结束有可用的静止画面，方块和推杆没有长时间完全遮挡。
- 抽查MediaPipe手关键点是否落在实际手部；不把仅能加载模型视为检测质量通过。
- 检查物体定位、推杆末端轨迹及接触过程能否辨认；手关键点不能替代推杆尖端。
- 检查标尺、标记位置和坐标方向，估计定位误差。
- 桌面标定只对应纸面高度。方块顶部和推杆标记存在高度差，不能直接把桌面单应性当作准确三维位置；后续需测量并处理。
- 不预先承诺检测通过率或任务成功率。试采质量确认后才冻结正式数据协议。

本轮只验证采集条件，不把模拟图片、生成视频或外部示例计入申请人自采数据。
