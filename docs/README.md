The current four-goal evidence is distributed in **v1.1.0**. The simple-transfer, outcome-prediction and early diffusion-policy evidence is in **v1.0.0**. These are versioned stages of the same project. Each package has its own environment files and input manifest; follow its corresponding guide.

[Historical design and delivery records](archive/README.md) document how the project was developed. Current instructions are the guides listed above.
