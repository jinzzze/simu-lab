## 标签含义

物体分支只使用当前 RGB 和首帧两枚 ArUco（DICT_4X4_50，ID 0、2）的平面参照。通过黑色连通区域的颜色、尺寸、形状与两阈值一致性筛选，排除标记与黑线，参照漂移时关闭物体监督。v2 加强面积支持与角点/相似变换漂移检查。没有未来终点、插值或上一帧位置补齐。

物体目标是可见黑色部分的框，不是遮挡物体的完整中心或三维位姿。阈值来自开发图像。标称 50 mm 标尺实测 48 mm，0.96 只是等比例打印假设，另一个方向未核实。

手部来自固定 MediaPipe Hand Landmarker 的逐帧 IMAGE 推理。唯一检测手用于 21 点二维监督，出界点独立屏蔽；inside_image 不是关键点置信度。手框重叠仅作质检，不影响物体标签或有效掩码，因此 B 没有暗中获得手部信息。无效辅助标签不删除 RGB。
