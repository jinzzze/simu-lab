# Execution and packaging scripts

[Quick replay](../docs/QUICKSTART.md) · [Training](../docs/TRAINING.md) · [Simple-task reproduction](../docs/SIMPLE_TASK_REPRODUCTION.md)

Use these guides to choose a complete workflow. Original-stage scripts cover video labels, simulation datasets, visual training, outcome prediction and diffusion commands. Package utilities verify downloads and prepare a fresh workspace for the four-goal training repeat. Some scripts regenerate fixed-path reports or protect existing output directories; their presence is not an instruction to run every script in this folder.
