# Recorded experiment artifacts

[Evidence index](../docs/EVIDENCE.md) · [Results explained](../docs/EXPERIMENTS.md)

This directory holds original-stage diagnostics, metrics, selected videos and frozen source snapshots. The four-goal records are under their experiment directories and in the v1.1.0 Release assets. Use the evidence index to find a result before browsing individual logs.

Machine-readable records retain their original source/configuration hashes and stage timestamps. Historical status fields are provenance, not current publication instructions. English study guides explain the measured results; original narrative records remain accessible in the pinned history.
